# 简历口袋：页面方案讨论稿

> 状态：设计建议，尚未实现。最后整理：2026-10-29。
>
> 本文把[产品需求](requirements.md)转换成可讨论的页面内容与操作流程。文字框图用于说明信息层级，不代表最终视觉稿。示例名称与内容均为虚构数据。

## 1. 设计目标

- 新访客在首页明白产品用途、如何开始以及分享链接的边界。
- 求职者在自己的工作区完成上传、预览、分享管理和统计查看；管理员可查看全站汇总。
- 招聘方打开分享链接后直接阅读简历，默认可以打印和下载。
- 首版已确定支持 PDF、DOCX 和 DOC 的上传、预览、打印和下载；Word 预览转换方案待验证。
- 页面风格遵循已确认的方向：简洁专业、克制、清晰、可信。
- 不向访客展示求职者的账户信息或仅供自己管理的公司、联系人备注。

## 2. 首页：让访客理解产品

### 桌面端结构示意

```text
┌──────────────────────────────────────────────────────────────┐
│ 简历口袋       产品功能   使用方式   常见问题     登录  开始使用 │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  把简历放在线上，              ┌────────────────────────────┐  │
│  随时分享给招聘方。            │      虚构的分享页示例       │  │
│                               │      [示例简历预览]         │  │
│  上传简历，为不同对象创建      │       查看  打印  下载       │  │
│  独立链接，并选择有效期。      └────────────────────────────┘  │
│  [开始使用]  [查看示例]                                      │
├──────────────────────────────────────────────────────────────┤
│  三步开始：  ① 上传简历 → ② 创建链接 → ③ 对方打开          │
├──────────────────────────────────────────────────────────────┤
│  保存与预览          按对象分享             自主管理链接       │
├──────────────────────────────────────────────────────────────┤
│  常见问题：支持什么文件？  对方需要账号吗？  链接会失效吗？   │
├──────────────────────────────────────────────────────────────┤
│  隐私说明    服务说明    联系方式    项目信息                  │
└──────────────────────────────────────────────────────────────┘
```

### 内容与行为

| 位置 | 建议内容 | 操作或判断 |
| --- | --- | --- |
| 导航 | 产品标识、产品功能、使用方式、常见问题、登录、开始使用 | 访客点击“开始使用”进入注册；已登录用户看到“进入工作区” |
| 首屏 | 说明保存 PDF、DOCX 和 DOC，为不同对象生成链接及选择有效期 | “查看示例”打开由虚构内容构成的分享页示例，不需要登录；只在格式支持上线后公开宣传 |
| 使用步骤 | 上传、创建链接、发送给对方 | 不暗示可以直接向招聘方发送邮件；首版由用户自行发送链接 |
| 功能说明 | 随时预览、打印和下载；每个对象独立链接；链接可停用 | 永久有效也是可选项；不能暗示所有链接都会自动过期 |
| 隐私边界 | 简历在个人空间内；拿到有效链接的人可以打开；链接可停用 | 不使用“只有指定的人能打开”或“绝对安全”等无法兑现的表述 |
| FAQ 和页脚 | 常见问题、隐私及服务说明、联系途径 | 只描述正式上线时实际存在的功能、政策与联系方式 |

### 首页文案示例（待讨论）

- 标题：**把简历放在线上，随时分享给招聘方。**
- 副标题：上传 PDF 或 Word 简历，为不同公司或联系人创建独立链接，并选择有效期。
- 主按钮：**开始使用**；次按钮：**查看示例**。
- 核心说明：链接到期或停用后无法继续打开；链接被转发后，持有链接的人仍可能查看。
- 文件说明：首版支持 PDF、DOCX 和 DOC；具体大小限制以上线时的规则为准。Word 在线预览需先完成转换，版式可能与原文件有差异。

### 手机端

导航收起为简洁菜单；标题、按钮和虚构示例按顺序纵向排列。主要按钮不被底部栏遮挡，正文和操作不产生横向滚动。首页的每个跳转目标都可通过键盘与触控使用。

## 3. 我的简历：完成主要操作

### 桌面端结构示意

```text
┌──────────────────────────────────────────────────────────────┐
│ 简历口袋        我的简历    分享管理    数据统计     账户菜单 │
├──────────────────────────────────────────────────────────────┤
│ 我的简历                                       [上传简历]   │
│ 保存、查看并分享你准备好的简历。                              │
├────────────────────────────┬─────────────────────────────────┤
│ 简历列表                    │ 当前选择：示例简历.pdf          │
│                            │                                 │
│ 示例简历.pdf                │                                 │
│ 日期 · 文件大小             │         PDF 多页预览            │
│ [分享] [更多操作]          │                                 │
│                            │                                 │
│ 产品设计简历.pdf            │       [打印] [下载] [分享]      │
└────────────────────────────┴─────────────────────────────────┘
```

### 列表和操作

- 空状态展示“还没有简历”，配“上传简历”；提示支持 PDF、DOCX 和 DOC，大小限制以最终产品规则为准。
- Word 上传后展示转换进度；分享前让求职者检查转换预览，失败时说明原因并提供重试或更换文件。更新失败或等待转换时，已有分享继续显示上一份可用版本。
- 文件列表显示名称、上传时间和大小；可预览、打印、下载、创建分享、更新这份简历或删除。
- “上传新简历”创建另一份简历；“更新这份简历”上传它的新版本。更新成功后，已有有效链接自动展示新版；界面应在更新前提示会影响已有分享。
- 删除时说明会使多少个关联链接失效，确认后再执行；部分操作失败时不能显示全部成功。
- 工作区内提供“分享管理”，让求职者查找对象备注、有效期与状态，复制有效链接、停用或重新启用链接。
- 用户登出或会话失效时应回到登录流程；重新登录后回到可用页面。

### 手机端

优先呈现简历列表和上传入口；选择文件后进入清晰的预览区域。打印、下载和分享操作保持可见或容易找到，但不遮挡简历内容。

## 4. 创建分享：一份简历、一个对象、一条链接

### 表单示意

```text
┌──────────────────────────────────────────────┐
│ 创建分享                                  ×  │
│ 当前简历：示例简历.pdf                       │
│                                              │
│ 公司或联系人备注                             │
│ [例如：某公司 · 招聘负责人               ]   │
│ 仅自己在分享管理中可见                       │
│                                              │
│ 公开信息卡（可选）    [选择此链接展示的字段] │
│ 未填写或未公开的字段不会展示                 │
│                                              │
│ 公开投递说明（可选）                         │
│ [例如：应聘产品经理岗位，感谢查阅。      ]   │
│ 持有效链接的人可见                           │
│                                              │
│ 有效期                                       │
│ [✓ 1 天] [2 天] [7 天] [自定义] [永久有效]   │
│ 默认选中：1 天                               │
│                                              │
│ 持有效链接的人可查看，默认可打印和下载。     │
│ [取消]                         [创建链接]    │
└──────────────────────────────────────────────┘
```

### 交互规则

1. 从某一份简历进入，页面明确显示当前分享的文件。
2. 允许填写仅自己可见的公司或联系人备注；**备注是否必填待确认**。
3. 选择此链接要展示的信息卡字段，并可选填写一条向接收方展示的投递说明；两者已确认纳入首版。公开内容不能自动使用私人备注或账户资料。
4. 分享前清楚展示哪些信息和留言会公开；不填写时无需显示空卡片。
5. 提供已确认的五种有效期选择，默认选中 1 天；自定义的具体输入方式待设计，不能接受过去的时间。
6. 如选择永久有效，清楚显示“不自动到期，可随时停用”。
7. 创建成功后展示可复制链接及有效期；复制失败时保留可手动选择的链接文本。
8. 展示简短说明：链接被转发后，持有有效链接的人也可能查看。
9. 防止重复提交；网络异常时说明结果并提供安全重试。

同一份简历更新成功后，已有有效链接在下一次打开时自动展示新版；链接的有效期和停用状态不变。新上传另一份简历不会改变旧链接。

## 5. 简历分享页：优先阅读

### 桌面端结构示意

```text
┌──────────────────────────────────────────────────────────────┐
│ 简历口袋          简历预览 · 通过链接查看                   │
├──────────────────────────────────────────────────────────────┤
│  可选公开信息：姓名 · 目标岗位 · 所在地 · 联系方式           │
│  可选投递说明：应聘产品经理岗位，感谢查阅。                  │
│  以上仅在求职者主动填写并选择展示时出现                     │
├──────────────────────────────────────────────────────────────┤
│  简历 · 共 2 页      [适应宽度] [- 缩放 +]    [打印] [下载]  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                 ┌────────────────────────┐                   │
│                 │                        │                   │
│                 │     简历预览第 1 页    │                   │
│                 │                        │                   │
│                 └────────────────────────┘                   │
│                 ┌────────────────────────┐                   │
│                 │     简历预览第 2 页    │                   │
│                 └────────────────────────┘                   │
│                                                              │
│       此简历由分享者提供        隐私说明 · 产品首页           │
└──────────────────────────────────────────────────────────────┘
```

- 页面使用统一的外围模板：PDF 保持上传文件的原有排版，Word 建议展示由原件转换并经求职者确认的预览；转换可能带来版式差异。
- 建议无须接收人登录；打印和下载为已确认的默认操作。
- 顶部用“简历预览”等通用标题和简短说明交代页面用途；页数、适应宽度与缩放帮助阅读，而非只放操作按钮。
- **公开信息卡（已确认纳入首版）**：求职者可选择公开姓名、目标岗位、所在地和联系方式，未填写或未选择展示的字段不出现；不自动从 PDF 或账户提取。
- **投递说明（已确认纳入首版）**：每条链接可自愿附上一句给接收方的说明；不填写时不显示。它与公司或联系人私人备注分开，不同链接的说明互不影响。
- 如公开联系方式，应由求职者明确选择；可考虑显示邮件或电话入口，但不代表平台会替用户发送消息。任何持有效链接的人都可能看到这些内容。
- 多页预览按顺序呈现，提供清晰页码；文件无法预览时说明原因，并保留可用的下载途径。建议默认下载 PDF、DOCX 或 DOC 原件。文字选择、全屏阅读与更新时间显示可作为后续增强评估。
- 手机端使简历适配屏幕宽度，操作不遮挡正文；如果设备无法直接打印，提示可下载后打印。
- 同一份简历更新后，重新打开链接应显示最新版本。已打开页面可能仍显示旧版；建议提示刷新，并确保同一页面内的预览、打印和下载对应一致版本。
- 不将真实简历、文件名、姓名或分享链接放入社交分享卡片、统计记录或第三方脚本；页面主体按权限正常展示简历预览。

### 状态文案示例

| 状态 | 建议文案 | 可用操作 |
| --- | --- | --- |
| 加载中 | 正在打开简历，请稍等 | 等待，必要时可重试 |
| 有效 | 简历预览 | 查看、打印、下载 |
| 手动停用 | 此分享已停用；5 秒后返回首页 | 新访问与停用前已打开的页面均显示提示；自动跳转产品首页，也可立即点击返回 |
| 不存在、已过期或文件已删除 | 链接不存在或已失效 | 联系分享人；这些状态是否自动跳转待确认 |
| 预览失败但可下载 | 暂时无法预览，可尝试下载原文件 | 下载或重试 |
| 网络/服务故障 | 暂时无法打开，请稍后重试 | 重试；不误报为链接过期 |

### 已停用页面示意

```text
┌──────────────────────────────────────────────┐
│ 简历口袋                                     │
│                                              │
│              此分享已停用                    │
│       如需查看，请联系分享者重新启用。       │
│                                              │
│           5 秒后将自动返回首页               │
│                [立即返回首页]                │
└──────────────────────────────────────────────┘
```

停用提示展示后 5 秒跳转到产品首页 `/`。如果接收方原本已打开页面，检测到停用时先移除简历、公开信息卡和投递留言，再显示该提示并开始计时；直接请求预览或原文件也不能获取文件。页面应主动检查状态，并在重新回到前台或网络恢复时再次检查。网络中断期间无法保证立即收到停用状态，不能把网络故障直接显示为停用。手动返回入口应始终可用，实现时应考虑脚本不可用的情况。是否展示逐秒倒计时可在设计时确定。

## 6. 数据统计与分享管理

### 用户后台示意

```text
┌──────────────────────────────────────────────────────────────┐
│ 简历口袋       我的简历   分享管理   数据统计        账户菜单 │
├──────────────────────────────────────────────────────────────┤
│ 我的数据                                              示例    │
│ [我的简历：3]      [分享链接：8]       [分享访问：24]         │
│ 生效 4  ·  已过期 2  ·  已停用 2          更新于：刚刚        │
├──────────────────────────────────────────────────────────────┤
│ 分享对象        简历           状态       访问次数    操作    │
│ 示例公司 A      示例简历       生效       12          停用    │
│ 示例公司 B      示例简历       已停用      5          重新启用 │
└──────────────────────────────────────────────────────────────┘
```

上述名称和数字均为虚构，仅说明布局。用户仅能查看自己的简历、分享状态及访问次数；管理员另有全站汇总，不默认展示其他用户的简历内容或私人备注。

- “停用”前说明原链接将无法继续打开；确认后更新状态。
- “重新启用”前提示持有原链接的人会重新获得访问能力。链接已过期时如何选择新期限待进一步确定。
- 访问次数不是已确认阅读人数；刷新和链接预览工具可能影响计数，数据可能有延迟；页面状态检查不应重复计作访问。
- 空数据、加载中和读取失败分别展示明确状态，不使用示例数字填充真实后台。

## 7. 视觉基础（候选方案）

以下是便于评审的初始方案，不是已经确认的品牌规范。首页可有适度品牌表达，工作区以操作效率为先，分享页以简历为中心。

| 用途 | 候选值 | 使用原则 |
| --- | --- | --- |
| 页面底色 | `#F5F7FA` | 温和的中性色，突出内容 |
| 内容底色 | `#FFFFFF` | 表单、卡片和简历外框 |
| 主要文字 | `#18283C` | 标题和正文；与页面底色对比度约 13.90:1 |
| 次要文字 | `#455468` | 说明、日期；与白色对比度约 7.72:1 |
| 主要操作 | `#234F86` | 主要按钮、关键链接；白色按钮文字对比度约 8.29:1 |
| 控件边界 | `#697D90` | 重要输入和控件边界；与白色对比度约 4.25:1 |

颜色对比度为上述具体组合的初步计算；最终界面仍需逐状态检查。字体优先使用适合中文阅读的系统无衬线字体；按钮与触控目标建议至少 44 × 44 像素。桌面、平板和手机分别检查布局，320 像素宽的窗口不应出现页面级横向滚动。

## 8. 评审时重点确认

- 首页的内容顺序、主标题和示例是否能让初次访问者快速理解产品。
- 分享表单的公司/联系人备注是否必填，以及自定义有效期如何输入。
- 公开信息卡的字段、显示顺序和编辑方式，以及修改信息卡后是否同步到已创建的链接。
- 多页阅读是否需要首版提供缩放、页码、适应宽度以外的辅助能力。
- Word 转换方式、可接受的版式差异、转换失败处理、文件大小限制和是否额外提供 PDF 下载。
- 已打开页面如何提示新版已发布，以及过期链接能否延长。
- 管理员汇总中的首页和分享页访问分别如何统计、已打开页面检测停用的时效目标，以及已过期的停用链接重新启用时如何选择有效期。

## 9. 后续验收建议

1. 在桌面与手机浏览器分别检查首页、空工作区、文件列表、创建分享、分享成功、有效分享页和失效页。
2. 分别用虚构的多页 PDF、DOCX 和 DOC 走通上传、预览、创建链接、接收方查看、打印、原件下载、停用与重新启用；检查 Word 转换效果及失败、更新中的处理。
3. 检查有效期选项、永久链接的停用、时间边界与自定义输入；新访问和已经打开的页面在检测到停用后都展示提示，并在提示出现 5 秒后返回首页。
4. 检查用户仅能查看自己的统计，管理员可查看全站汇总；核对访问次数不会由 PDF 分页请求或状态检查重复增加。
5. 检查键盘操作、焦点顺序、可读性、加载/错误/空状态以及较窄屏幕。
6. 不以这份讨论稿声称相关页面或功能已经上线；实现后再以真实页面和测试结果验收。
